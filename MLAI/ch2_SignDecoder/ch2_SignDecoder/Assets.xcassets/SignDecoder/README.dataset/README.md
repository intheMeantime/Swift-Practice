# SignDecoder: Extract text from images

Create an app that recognizes text in photos of trail signs. Use the Vision and Translation frameworks to extract text from an image and translate it into another language.

## Overview

These resources are associated with the [Recognize text in images] (https://developer.apple.com/tutorials/develop-in-swift/extract-text-from-images) tutorial. This is part of the [Machine learning and AI](https://developer.apple.com/tutorials/develop-in-swift/welcome-to-machine-learning-and-ai) tutorials from [Develop in Swift](https://developer.apple.com/tutorials/develop-in-swift) by Apple.

## Using these resources

Follow the tutorial instructions in section one of [Recognize text in images tutorial](https://developer.apple.com/tutorials/develop-in-swift/extract-text-from-images) to use these resources within the Xcode app.
